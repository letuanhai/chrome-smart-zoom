SUMMARY (manifest "description", max 132 chars)
Double right-click any part of a web page to smoothly zoom in on it. Press Esc or double-click again to zoom back out.

DETAILED DESCRIPTION
SmartZoom brings the macOS "smart zoom" gesture (two-finger double-tap) to Chrome and other Chromium browsers on any operating system.

HOW IT WORKS
• Double right-click on any element of a web page (a paragraph, table, image or chart) and SmartZoom smoothly zooms in so that element fills the window.
• Double right-click again, or press Esc, to zoom back out.
• A single right-click still opens the normal context menu.

SETTINGS
Click the SmartZoom toolbar icon to change:
• Zoom trigger: double right-click (default), double middle-click, or none. Middle-click keeps the context menu completely untouched.
• Context menu entry: add "SmartZoom: zoom in / out" to the right-click menu to zoom without double-clicking.
• Zoom padding: space left around the zoomed element (0–500 px).
• Transition duration: speed of the zoom animation (0–2000 ms).
Settings are saved with Chrome sync and take effect immediately.

PRIVACY
SmartZoom works entirely in the page you are viewing. It collects no data, makes no network requests Its only permissions are "storage" (to remember your settings) and "contextMenus" (for the optional right-click menu entry).

WHAT'S NEW IN 1.2
• New settings popup: choose the zoom trigger, padding and animation speed.
• Optional right-click menu entry to zoom in / out, and a "none" trigger to turn off double-click zooming.
• Removed mouse panning while zoomed for a steadier zoom.
